# 教師操作與解答

## 課堂操作

同一組可用一台裝置，由組員輪流控制儀器、記錄算式和說明證據。分成兩節時，可在任一驗收步驟暫停，下次用同一台裝置與瀏覽器續玩。角色位置、讀過的區域介紹、已拾取的核心、地圖採樣與設定、提示和筆記會保留。用「區域故事」可以重看這一區的開場。尚未驗收的儀器視窗在重新整理後會回到初始值。若學生找不到目標，點右側「帶路」，抵達後按 **E** 或互動鍵。

### 開放或鎖定章節

右上角齒輪可設定目前瀏覽器的章節鎖定。若要統一鎖定演化章，在 [settings.ts](../src/data/settings.ts) 把 `lockedChapters` 改成 `['evolution']`，再推送至網站的 `main`。到開放日再改回 `[]` 並推送。鎖住一區時，角色無法穿過閘門。開放後仍需裝回前一區的電源核心，才可前往。終章需要八區全數完成。

### 編輯題庫

在 [chapters.ts](../src/data/chapters.ts) 或 [finale.ts](../src/data/finale.ts) 搜尋題目標題。每題的 `objective` 是學習目標，`prompt` 是題目，`hints` 是逐級提示，`success` 和 `retry` 是驗收回饋，`evidence` 是記入學生筆記的內容。保留原有 ID 可接續學生存檔。若替換題目的學習任務，可用新 ID 讓該題重新驗收。

| 題型 | 答案設定 |
| --- | --- |
| 數值 | `fields` 列出欄位、單位、`answer` 和選用的 `tolerance`。 |
| 讀圖 | `graph` 定義軸、測量點與 `answerX`。`xTickLabels` 可放「雨停」這樣的刻度名稱。圖下方的答案、單位和提示放在 `fields`。 |
| 配平 | `reactants` 與 `products` 定義化學式、原子數與參考係數。`maximumCoefficient` 控制托盤的最大數字。驗收依原子守恆和最簡比。 |
| 研判 | 在正確選項填 `correct: true`，`select` 是選取數，`consequence` 是該方案的後果。 |
| 探針與電池 | `samples` 和 `targets` 對應樣本與分類。鋅銅電池分別設定左右電極與參考電壓。 |
| 模擬控制 | `model` 放模型參數，`controls` 定義可調範圍，`metrics` 的 `min` 和 `max` 是通過門檻。模型算式在 [models.ts](../src/engine/models.ts)。 |

修改數字時，同步核對題幹、答案、提示、證據、[現場旋鈕與分流選項](../src/data/field.ts) 及 [測試解答](../tests/solutions.mjs)，再執行 `npm test` 和 `npm run build`。各艙的額外對話和錄音在 [station.ts](../src/data/station.ts)。

## 參考答案

| 區域／關卡 | 通過條件與推理 |
| --- | --- |
| 01 · 找出 3,000 的標籤 | 選 3 × 10³。10³ 是三個 10 相乘。 |
| 01 · 備份一共有幾份？ | 8 份。1 → 2 → 4 → 8，每層加倍。 |
| 01 · 把兩箱卡片分成一疊一疊 | 每疊 6 張。12 和 18 都能整除，6 是兩箱都分得完的最大每疊張數。 |
| 02 · 螢幕的 12 格代表什麼？ | 點 4 mA、12 格，填 4 mA。下方是實際電流，左邊是螢幕格數。 |
| 02 · 雜訊什麼時候低於 10？ | 點第 2 分鐘。雜訊由 32 降到 8，填減少的 24。 |
| 02 · 找出 A 泵每分鐘送多少水 | 選 5 L/min。開多一台 A，使 8 變成 13。 |
| 03 · 追蹤丙烷反應後的原子 | C₃H₈ + 5 O₂ → 3 CO₂ + 4 H₂O。係數依序 1、5、3、4。每邊有 3 個碳、8 個氫、10 個氧。 |
| 03 · 密閉盒還剩多少材料？ | 8 g。20 g 總質量扣掉 12 g 水。 |
| 03 · 槽外的水變熱了 | 反應放熱，外側水收到熱才會變暖。 |
| 04 · 哪一瓶是酸水？ | B 是酸水，A 是 pH 7 且明顯導電。四瓶先全部量過。 |
| 04 · pH 少一格，差幾倍？ | 約 10 倍。pH 3 的氫離子濃度約是 pH 4 的 10 倍。 |
| 04 · 讓水槽的酸剛好用完 | 3 劑。每劑抵銷 2 格，要剛好抵銷 6 格。 |
| 05 · 幫備援電池接上零件 | 左黑端接 Zn，中間放鹽橋，右紅端接 Cu。電表顯示 +1.10 V。 |
| 05 · 鋅片失去電子，這叫什麼？ | 氧化。鋅失去電子，銅離子得到電子是還原。 |
| 05 · 電壓升高，電流會變多少？ | 點 6 V、2 A。第一格填 2 A，第二格由 12 V ÷ 3 Ω 得 4 A。 |
| 06 · 給小苗足夠的光和水 | 燈 2 段，水 4 或 6 段。淨吸收達 3 mmol/h，照明 4 W。 |
| 06 · 葉片做了幾份糖？ | 2 份。每 6 份氧氣對應 1 份葡萄糖。 |
| 06 · 關燈後的小苗在做什麼？ | 用已有的糖呼吸，釋出 CO₂ 並獲得能量。 |
| 07 · 把多出的 5 格碳收回來 | 減排和新增吸收合計至少 5 格，且保留至少 1 桶水。例：減排 3、植物吸 2。 |
| 07 · 雨後的水跑去哪裡？ | 點水量最高的「雨停」，有 14 桶。蒸發掉 14 − 12 = 2 桶，最後剩 12 桶。 |
| 07 · 哪一次進出剛好相同？ | 點第 2 次，吸收和送出都是 8 W/m²。圖下方填第 3 次的差值 8 − 6 = 2 W/m²。 |
| 08 · 哪一代首次有一半是厚殼？ | 點第 2 代，厚殼 6 隻，圖下方填 60%。半數的門檻是 5 隻。 |
| 08 · 乾季裡哪一種留下更多後代？ | 厚殼。乾燥箱留下 6 隻，薄殼組留下 2 隻，厚殼也能遺傳。 |
| 08 · 誰跟岸紋甲比較像親戚？ | 沼紋甲。相同的雙節構造，同段 DNA 只差 2 處。 |
| 終章 · 14 格不是 14 mA | 5 mA。先扣掉 4 格，再除以 2。 |
| 終章 · 把備用電分給三台機器 | 水質處理 2 批、抽水和照明各 2 段。合計 6 Wh。 |
| 終章 · 什麼事情讓電先斷掉？ | 控制器先誤把 14 格當 14 mA，之後才切電。 |
| 終章 · 要怎麼把電送回去？ | 查新量測和單位，再依序讓各區復電。 |
