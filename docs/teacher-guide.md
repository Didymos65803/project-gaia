# 教師操作與解答

## 課堂操作

同一組可用一台裝置，由組員輪流控制儀器、記錄算式和說明證據。分成兩節時，可在任一驗收步驟暫停，下次用同一台裝置與瀏覽器續玩。進度、已揭開的提示和科學筆記會保留，正在填寫的關卡儀器會回到初始值。

### 開放或鎖定章節

右上角齒輪可設定目前瀏覽器的章節鎖定。若要統一鎖定演化章，在 [settings.ts](../src/data/settings.ts) 把 `lockedChapters` 改成 `['evolution']`，再推送至網站的 `main`。到開放日再改回 `[]` 並推送。鎖住一區時，劇情需待該區開放並完成才能繼續。終章需要八區全數完成。

### 編輯題庫

在 [chapters.ts](../src/data/chapters.ts) 或 [finale.ts](../src/data/finale.ts) 搜尋題目標題。每題的 `objective` 是學習目標，`prompt` 是題目，`hints` 是逐級提示，`success` 和 `retry` 是驗收回饋，`evidence` 是記入學生筆記的內容。保留原有 ID 可接續學生存檔。若替換題目的學習任務，可用新 ID 讓該題重新驗收。

| 題型 | 答案設定 |
| --- | --- |
| 數值 | `fields` 列出欄位、單位、`answer` 和選用的 `tolerance`。 |
| 讀圖 | `graph` 定義軸、測量點與 `answerX`，其餘數值放在 `fields`。 |
| 配平 | `reactants` 與 `products` 定義化學式、原子數與參考係數。驗收依原子守恆和最簡比。 |
| 研判 | 在正確選項填 `correct: true`，`select` 是選取數，`consequence` 是該方案的後果。 |
| 探針與電池 | `samples` 和 `targets` 對應樣本與分類。鋅銅電池分別設定左右電極與參考電壓。 |
| 模擬控制 | `model` 放模型參數，`controls` 定義可調範圍，`metrics` 的 `min` 和 `max` 是通過門檻。模型算式在 [models.ts](../src/engine/models.ts)。 |

修改數字時，同步核對題幹、答案、提示、證據及 [測試解答](../tests/solutions.mjs)，再執行 `npm test` 和 `npm run build`。

| 02 · 找出兩條管線流量 | A = 12 L/min，B = 6 L/min。兩式相減消去 B。 |
| 03 · 重建反應式 | CH₄ + 2 O₂ → CO₂ + 2 H₂O。每側 C 1、H 4、O 4。 |
| 03 · 找回未被秤到的質量 | 44 g CO₂、8 g O₂、52 g 共計。被碳消耗的氧氣只有 32 g。 |

| 04 · 追蹤酸度尺度 | 1、0.01 mmol/L，100 倍。兩個 pH 單位相差 10²。 |
| 04 · 設定回流槽中和量 | 6 劑。每劑可消耗 3 mmol 酸當量，18 ÷ 3 = 6。 |
| 05 · 接通鋅銅監測電池 | 左 Zn、右 Cu、接通鹽橋。紅端在右所以讀 +1.10 V。 |
| 05 · 追蹤兩種載流者 | Zn 失去 2e⁻，Cu²⁺ 得到 2e⁻。外電路由電子載流，鹽橋由離子載流。 |
| 05 · 檢查監測負載 | 2.20 V、20 mA、44 mW。串聯電壓相加後用歐姆定律，功率為電壓乘電流。 |

| 06 · 盤點氧氣與葡萄糖 | 12、2.5、2 mmol。氧氣淨量 15 − 3，氧氣對葡萄糖的反應量比是 6 : 1。 |
| 06 · 分辨暗處的氣體交換 | 黑暗仍可有氧呼吸。比較組控制溫度和起始 CO₂，只改變光照，另設無葉片空白艙。 |
| 07 · 讓大氣碳庫停止上升 | 減排＋復育至少 15 kg C，復育至多 4 kg C，例如減排 12、復育 3。 |
| 07 · 辨認水流的去向 | 124、4、7 m³。今日收支單獨計算，追蹤回流屬於隔天。 |
| 07 · 定位輻射失衡情境 | 標記情境 3，填 12、112 W/m²。淨吸收＝入射短波 − 反射短波 − 出射長波。 |
| 08 · 讀出族群性狀頻率 | 標記第 3 世代，填 50 個百分點、6 倍。60% 與 10% 分別做減法和除法。 |

| 08 · 比對標本的親緣關係 | 岸紋甲、沼紋甲較近。較晚出現的共同雙節構造與 DNA 比對一致。 |
| 終章 · 複核觸發隔離的讀值 | 12 mA、3 mA、34 格。先校正物理量，再比較門檻。 |
| 終章 · 配置跨區重啟預算 | 處理 4 批、供水 4 段、照明 5 段。酸歸零，庫水剩 6 m³，淨吸碳 8，耗電 30 Wh。 |
| 終章 · 重建事故因果鏈 | 標籤遺失誤判過電流，隔離導致補光停止並改變淨碳通量。局部酸樣獨立查核。 |
| 終章 · 決定全站復電條件 | 分區重啟，核對即時量測、門檻與收支，保留各環境族群對照。 |
