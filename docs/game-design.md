# 遊戲設計

## 故事與流程

玩家來到研究站，原本要和何研究員替小苗的第一片葉子拍照。停電後，備援機器人 GAIA 請玩家幫忙找回紀錄。林工程師查電流和管線，周博士量反應與水樣，何研究員確認小苗和甲蟲究竟發生了什麼。不同房間的證據共同指向停電前被移除的量測單位。

每個房間第一次進門都會先停在現場，播放一段有旁白和人物的介紹。走近研究員再談時，角色會用日常例子示範第一個任務。玩家可以重看區域故事，也能在房間裡拾取錄音，讀到原始紀錄和角色的解釋。

每道數值題專注一個結果，讀圖題直接點圓點。解完一區的三道關卡後，把電源核心送回插座，才會開下一區的門。對話會告訴玩家下一站以及為什麼要去那裡。現場採樣、故事進度、錄音和筆記可隨存檔接續。

## 課程目標與預估節奏

時間是設計估算，包含在研究站移動、讀簡報、動手試驗與簡短討論。各區可規劃約 60–120 分鐘的課堂活動。遊戲內的答題更短，實際需要的時間取決於閱讀、移動、角色分工和口頭解釋。各區筆記保留一題討論題，教師可請學生口頭說出算式、反例或對照證據。

| 區域 | 時間（分鐘） | 三項操作與學習目標 |
| --- | ---: | --- |
| 01 密碼失控 | 6–10 | 科學記號與秒／微秒；整數次方與分頁；質因數分解與最大公因數。 |
| 02 數學控制中心 | 7–12 | 從圖上讀格數和電流；找雜訊減半的門檻；用前後差值找出 A 泵的流量。 |
| 03 化學反應實驗室 | 7–12 | 最簡係數與原子守恆；密閉盒內的總質量；從周圍水溫辨別放熱。 |
| 04 酸鹼污染事件 | 7–12 | 雙探針辨別酸、鹼與導電性；以十的次方讀 pH；依酸鹼當量中和。 |
| 05 能源系統修復 | 7–12 | 裝配鋅銅電池與鹽橋；追蹤電子和離子；由電壓和電阻算電流。 |
| 06 生物實驗溫室 | 7–12 | 找光合作用限制因子；算光合作用做出的糖；解釋關燈後仍會呼吸。 |
| 07 地球氣候控制室 | 8–13 | 碳庫與水資源分配；下雨與蒸發如何改變水量；找出熱進出相同的圖表測試。 |
| 08 生態演化研究區 | 8–13 | 比較各世代厚殼占比；聯繫遺傳與繁殖表現；比較衍生構造、化石與 DNA。 |
| 終章 全站重啟 | 12–20 | 複核感測器警報；配置中和、給水、照明及用電；重建因果鏈；從證據挑選驗收流程。 |

## 模型與驗證

- 數值以欄位的固定單位驗收，接受小數、正負號、全形數字與 `e` 表示的科學記號。整數題檢查精確值，部分小數題允許題庫所列的絕對誤差。
- 配平驗算各元素左右原子總數，以及係數的最大公因數。讀圖題點選符合條件的圓點，圖上會引導視線回到兩軸，也有可選取的資料表。
- 鋅銅電池以兩半電池和鹽橋呈現。電流題採理想電壓源，溫室和氣候控制採題目明列的簡化模型。酸鹼處理題依已知當量核算。
- 題目與現場狀態都是確定性的。回到已通電的設備可查看驗收解釋，再從初始設定演練。
