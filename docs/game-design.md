# 遊戲設計

## 故事與流程

研究站的備援系統 GAIA 在 05:40 偵測到同步中斷。玩家以新進研究員的身分找回事件紀錄，跟隨林工程師、周博士與何研究員的通訊逐區調查。工作假設會隨資料更新。正確的讀值能排除一些故障，實驗證據也可能確認局部問題仍需要處理。終章重新驗算警報門檻、分配資源、重建時間線並選擇復電流程。

玩家操控一個小研究員，沿著相通的走廊穿越艙門。角色靠近同事才能展開對話，靠近設備才能操作。黃色驚嘆號和自動帶路可協助定位。走訪不同設備能直接影響實驗，例如實際掃描水樣、搬運鋅銅電池零件，或在溫室內調整照明與給水。設備會顯示即時讀值，試驗結果會指出判斷與觀測哪裡衝突。

完成一區的驗收後，玩家要拾取電源核心並裝到區域插座。艙室恢復通電，下一道門隨即打開。通過的實驗、撿到的失聯錄音和自訂筆記都會保留，已通電的區域可再走回去演練。每道題有兩級提示。

## 課程目標與預估節奏

時間是設計估算，包含在研究站移動、讀簡報、動手試驗與簡短討論。各區合計約 69–116 分鐘，實際節奏會隨學生先備知識、提示使用和討論深度而變化。各區筆記保留一題討論題，教師可請學生口頭說出算式、反例或對照證據。

| 區域 | 時間（分鐘） | 三項操作與學習目標 |
| --- | ---: | --- |
| 01 密碼失控 | 6–10 | 科學記號與秒／微秒；整數次方與分頁；質因數分解與最大公因數。 |
| 02 數學控制中心 | 7–12 | 線性斜率、截距與校正；指數衰減與門檻；二元一次聯立方程。 |
| 03 化學反應實驗室 | 7–12 | 最簡係數與原子守恆；限量反應物與質量守恆；從周圍溫度辨別吸放熱。 |
| 04 酸鹼污染事件 | 7–12 | 雙探針辨別酸、鹼與導電性；以十的次方讀 pH；依酸鹼當量中和。 |
| 05 能源系統修復 | 7–12 | 裝配鋅銅電池與鹽橋；追蹤電子、離子與氧化還原；串聯、歐姆定律與功率。 |
| 06 生物實驗溫室 | 7–12 | 找光合作用限制因子；依反應比計算氧氣與葡萄糖淨量；以對照實驗確立呼吸和 ATP 的角色。 |
| 07 地球氣候控制室 | 8–13 | 碳庫與水資源分配；水流邊界與蒸發回流；由長波圖表求淨輻射收支。 |
| 08 生態演化研究區 | 8–13 | 量化跨世代性狀比例；聯繫遺傳與繁殖表現；比較衍生構造、化石與 DNA。 |
| 終章 全站重啟 | 12–20 | 複核感測器警報；配置中和、給水、照明及用電；重建因果鏈；從證據挑選驗收流程。 |

## 模型與驗證

- 數值以欄位的固定單位驗收，接受小數、正負號、全形數字與 `e` 表示的科學記號。整數題檢查精確值，部分小數題允許題庫所列的絕對誤差。
- 配平驗算各元素左右原子總數，以及係數的最大公因數。讀圖題需標記符合條件的資料點並完成數值計算。
- 鋅銅電池以兩半電池和鹽橋呈現。電路功率題採理想電壓源，溫室和氣候控制採題目明列的簡化模型。酸鹼處理題依已知當量核算。
- 題目與現場狀態都是確定性的。回到已通電的設備可查看驗收解釋，再從初始設定演練。
